# CIE 2 – Machine Learning Activity 2
## Simple House Price Prediction using Linear Regression

### 1. Objective
To build a Simple Linear Regression model that predicts house prices using house area as an input feature.

### 2. Dataset
- **Dataset Name:** Housing Price Prediction
- **Source:** [Kaggle – Housing Price Prediction](https://www.kaggle.com/datasets/yasserh/housing-prices-dataset)
- **File:** Housing.csv
- **Input Feature:** Area
- **Target Variable:** Price

### 3. Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### 4. Implementation Steps
1. Loaded and explored the housing dataset.
2. Checked missing values and duplicate records.
3. Performed data cleaning.
4. Selected area as the input feature and price as the target variable.
5. Visualized the relationship between area and price.
6. Split the dataset into 80% training and 20% testing data.
7. Trained a Simple Linear Regression model.
8. Predicted house prices using test data.
9. Evaluated the model using MAE, MSE, RMSE and R² Score.
10. Visualized actual and predicted house prices.
11. Predicted the price of a new house.

### 5. Model
Simple Linear Regression:

Price = Intercept + (Coefficient × Area)

### 6. Evaluation
The model was evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

Actual evaluation values are available in the executed Google Colab notebook.

### 7. Conclusion
A Simple Linear Regression model was successfully developed to predict house prices based on house area. The activity demonstrates the application of supervised learning and regression techniques for predicting continuous numerical values.
